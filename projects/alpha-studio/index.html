Overview

总览与产品定位

一条自动化漏斗：把表达式生成、质检门禁、WQ 回测、评估晋级与反馈权重串成闭环，研究者只做决策。

核心漏斗 README · AGENTS.md

生产层template / agent / feedback
模板 + 字段概率化（YAML 规则引擎）、Agent 探索式生成、基于反馈权重的生成 → 写入 PG alpha_pool + Redis per-strategy RAW 池（8 策略，DEC-278）。
↓
质检层quality
14 道质检链（语法 → 字段 → 算子元数 → 结构 → 去重 → 质量分 → 反模式…）→ Redis SET(QUALIFIED) + stream:qualified。
↓
模拟层simulate → WQ 回测
提交表达式到 WorldQuant 回测，硬上限 3 个在飞 POST（SubmissionGate），带优先级出队、限流冷却与熔断。
↓
结果处理pipeline
轮询 WQ 完成事件 → 写 PG → 立刻还槽（槽位释放走 outbox 事务补投，DEC-266）。
↓
评估晋级 / 反馈evaluation · submit · feedback
7PASS 评估、候选排序与配额提交（WQ_SUBMIT_MODE=manual，DEC-217 人工提交）；结果写回 feedback_weights 与通道权重，供下一轮生产。
硬规则：所有 WQ 操作必须经过 Backend API，绝不直接调 WQ；WQ 侧只有 UNSUBMITTED / ACTIVE 两态，7PASS 因子必须人工提交；PG 是事实源，Redis 只是临时协调设施。

Worker 运行时机制 BaseWorker 731 L · WorkerManager 596 L

循环与退避

  • setup() → cycle() → teardown()；连续失败 10 次停止，错误睡眠 2×cycle_interval。
  • 空转指数退避（DEC-169）：min(15s × 2ⁿ, 300s)，任何工作恢复基准间隔。
  • 心跳/看门狗：每 cycle 写 worker:heartbeat:{name}；看门狗 30s 一跳，陈旧阈值 max(600s, 2×cycle, 观测最大 cycle×1.5)；进程内模式绝不 os._exit，只停循环交给 WorkerManager 重启。
  • 每 cycle 结束 _release_db_transaction()，避免 idle-in-transaction 与 Docker NAT 掉连。

WorkerManager 托管

  • 单例 + 每 worker 一个 asyncio task；同步 cycle() 经 asyncio.to_thread 执行（sim worker 内部可再 asyncio.run）。
  • 自动重启：最多 3 次，延迟 5s × 2ⁿ，运行满 600s 重置计数；显式 stop 打 _stopping 防僵尸重启。
  • 优雅停机：cancel task → 等 CancelledError → 线程里跑 teardown → 写 status=stopped → 注销（保证 /status 不撒谎）。
  • 配置来自 Redis hash production:worker:{name}:config，覆盖 config/alpha_config.yaml 默认值；启动顺序保证 迁移先于 worker（避免 AccessShareLock 卡死 ALTER）。

1. 表达式生成：五通道分配 DEC-231-F / 269

generation/service/orchestration/channel_router.py · ChannelRouter
默认配比
DEFAULT_WEIGHTS = {template .20, grammar .20, hybrid .20, random .20, ast_engine .20}——五路均分，allocate(target_batch) 整数切分，余数给最高权重通道。
预算纪律
empty_budget / leftover_sinks / split_budget 保证「未用预算只流向已满通道，绝不倒给 random」；random 只是最后兜底地板 EXPLORE_FLOOR = 0.05，且需要 PASS_RATE_MIN_N = 5 样本才参与自适应。
自适应混合
with_pass_rates()：先验 × (floor + (1−floor)·clip(pass_rate,0,1)) 再归一化；with_outcome_weights()：先验 × clip(w, 0.3, 1.8)（跨 key 取最小），random 恒有下限。
家族先验
momentum .2 / value .2 / quality .15 / volatility .15 / growth .15 / liquidity .1 / reversal .05；20% 流量跑 family_weight_experiments 与 winner_bias_experiments（group_rank 0.85、vwap×3.0、adv20×2.5）A/B。
种子来源
Redis ZSet alpha:feedback:by_sharpe（_sample_feedback_seeds(min_sharpe=1.0)）+ PG find_qualified_expressions(min_sharpe=1.25)。
整数预算分配通过率自适应探索地板 5%A/B 家族权重

7. 反馈闭环：经验贝叶斯权重

workers/feedback/feedback_worker.py（DEC-226/273）· SSOT 表 feedback_weights
边① 算子 ← 质检失败
横截面做 Beta-Binomial 经验贝叶斯先验（矩估计），后验率 (successes+α)/(n+α+β)，然后 weight = clamp(1.0 + 0.6 × (posterior_rate − prior_rate), 0.3, 1.8)——高于先验给奖励（>1），低于先验惩罚（<1）。
边②③④ 模板 / 策略家族 / 字段
