01
Stage 01 — Story / 策划 · 剧本

先让故事自己站得住，再动手画。

这一阶段的产出是「大纲 + 分页节拍 + 文字台本」。检验标准很简单：不看画面，只读文字，能不能被打动。

01

起 · 建立世界

P1 用一整页立住设定：月光会碎，人们用网兜去接。老人的职业、性格、孤独感，在没有一句台词的情况下全部交代清楚。

02

承 · 一次拒绝

P2–P5 女孩上门，老人拒绝、僵持、回忆、破例。冲突不是"能不能修"，而是"敢不敢再看一眼"。中段必须有情绪下坠。

03

转合 · 不复原的选择

P6–P8 修补不是高潮，放弃复原才是。他把碎月做成一盏灯——主题在这一刻落地：有些光，不必回到天上。

分页节拍表（Page Beats）

目标 / 情绪 / 翻页钩子

PAGE 事件 情绪曲线 翻页钩子（Page-turn hook）
01 夜空裂开，月光像玻璃一样坠落；城市居民张网去接。补月铺内景，老人独自工作。 静 → 好奇 末格：敲门声。老人的手停住。
02 门口站着抱铁盒的女孩。她摊开手心，一片有温度的碎月。老人：「不修私人的。」 紧张 → 拒绝 末格：女孩把手收回怀里，坐在门槛上不走。
03 深夜，女孩仍坐着。老人从窗内望出去，碎月里浮现画面——一间病房的窗帘。 僵持 → 不安 末格：老人的瞳孔放大，圆眼镜反光。
04 回忆：十年前病房，女儿把最后一片月光塞进他手里。「爸，帮我留着。」 下沉 → 疼 末格：回到现在，老人的手在发抖。
05 老人起身，打开多年未动的工具箱，拧亮台灯。「今晚……破个例。」 转折 → 蓄力 末格：灯光亮起的瞬间，画面全白。
06 修补过程。碎片拼合，画面浮现：女儿的笑。老人手抖，停住。 高潮 → 屏息 末格：他没有把它拼回月亮，而是拿起了提灯。
07 碎月被嵌进旧提灯。灯亮起。老人第一次露出笑。 释放 → 温暖 末格：提灯被递到一双小手里。
08 女孩提灯走进小巷。远处的城市里，第一次有人停下脚步抬头看天。 余韵 → 希望 无钩子。留白收尾，静止一拍。

文字台本节选 · 第 6 页（高潮页）

  • 格1（全宽·俯视）：工作台。台灯光锥切开黑暗，工具散落，中央的碎月发出低亮度的光。无台词。停留 3 秒。
  • 格2（半页·左）：老人侧脸特写。圆眼镜反光遮住眼睛，嘴唇微张。气泡：「……原来是妳。」
  • 格3（半页·右）：碎月中浮现的画面（回忆框）：病房窗帘，一只手伸向窗外。旁白：无。让画面自己说话。
  • 格4（全宽·中）：老人背影，双手拢在胸前，光从指缝间漏出。拟声词：「嗡——」细小、持续。
  • 格5（大格·底）：提灯亮起，老人站在窗边，脸朝外。旁白框：「有些光，不必回到天上。」

Stage 02 — Design / 人设 · 世界观

角色要有可辨识的剪影，和"演戏"的余地。

本作的配色纪律极其严格：整部作品只有一个饱和色——红色围巾。它是情绪指示器，只在最后一页扩散。

场景设定 · 三个必须立住的空间

空间即情绪

  • 补月铺：临街老铺，玻璃柜里按年月码放着碎月光，满墙工具，一盏永远亮着的台灯。暖色调、密集、充满细节——是"记忆的仓库"。
  • 门槛：内外的分界线。全篇最关键的调度位置：女孩坐在门槛上，老人在门内，两人隔着一条光的边界对峙了整整两页。
  • 夜空：巨大的裂纹像碎掉的瓷，冷蓝、辽阔、破碎。与室内的暖黄形成全篇唯一的冷暖对比。

ネーム草稿 · 名称分镜（等比 B5）
页面结构
5 格，视线动线呈 Z 字：俯视 → 左（脸）→ 右（回忆）→ 中（背影）→ 底（大格）。最后一格占页面 34%，是全篇停留时间最长的一格。
镜头语言
G1 交代空间 → G2/G3 双线并置（现实 vs 回忆）→ G4 中景制造距离感 → G5 远景收束。不使用仰角：全篇保持平视与俯视，让读者像旁观者一样靠近。
信息密度
G1 密度最高（工具、碎月、光锥），G3 密度最低（回忆必须干净），G5 中等。密度有起伏，页面才呼吸。
气泡排布
G2 的气泡放在左上角，让读者先看眼睛再读台词；G5 的旁白框压在右下角留白处，与提灯形成对角线平衡。气泡绝不压住手部。
灰度预算
黑 22% / 深灰 30% / 浅灰 18% / 留白 30%。全篇最亮的一格是 G5 的提灯——亮部必须留给它。
翻页钩子
G5 末尾：老人没有把碎月拼回天空，而是伸手拿起了提灯。读者必须翻到 P7 才知道他要做什么。
分镜自检三问 ① 这一格删掉，故事还成立吗？——不成立就留，成立就删。
② 读者的视线会落在哪里？——如果答案是"不知道"，重排。
③ 读完这一页，我有没有想翻下一页的冲动？
04
Stage 04 — Ink / 草稿 · 线稿

线的粗细，就是情绪的音量。

本作是夜戏，线稿必须"稳而轻"。以下是锁定下来的三条规则，一旦定稿就不再改动。

线重分层规则

外轮廓 · 0.8mmOUTLINE / 剪影边界
结构线 · 0.4mmCONSTRUCTION / 体块转折
氛围线 · 0.2mmATMOSPHERE / 速度线、发丝

光源设定

主光 / 补光 / 反差

  • 主光：台灯，位于画面左上，暖黄，45° 切入。所有阴影以此为准。
  • 补光：月光，冷蓝，从窗外右上方来，只提亮轮廓边缘。
  • 反差纪律：老人的圆眼镜反射主光，遮眼时代表回避；反射消失（露出眼睛）只在 P7 出现一次。
  • 手部：全篇特写 4 次（P2 掌心、P4 传递、P6 拼合、P7 递灯），需要专项参考。

勾线流程

从草稿到清稿

  • ① 分镜放大 200%，定人体与透视（3D 人偶打底）
  • ② 铅笔层：只定结构，不画细节
  • ③ 勾线层：先外轮廓后内部，一气呵成不回描
  • ④ 转折处提笔留气口，避免线条"闷死"
  • ⑤ 交叉线（袖口、腋下、颌下）加粗，体积感即刻出来
  • ⑥ 擦除草稿，检查是否有"漏光"（该闭合的形没闭合）

G10 · 10% 网点

用于夜空与空气感。几乎看不见，但能压住大面积白，避免"纸片感"。P1 的天空整片使用。

G30 · 30% 网点

墙面、桌面、衣物的中间调。本作使用量最大（约占全篇 30%），是画面的"底盘"。

G60 · 60% 网点

阴影与暗部。贴在物体背光面，与实地黑衔接。P3 整页加重使用，制造压抑。

速度线 · 集中线

只在 P5 末格与 P6 G5 使用，全篇不超过 3 次。稀有，才有冲击力。

Stage 06 — Type / 文字 · 输出

字也是画面。气泡也是演出。

本作台词极少，所以每一个字的字体、位置、气泡形状都承担着叙事重量。

22 天执行排期

一个人画完八页的现实节奏

D1–D4

企划与设定

  1. 写完大纲与八页节拍表
  2. 三个人设定稿 + 场景设定
  3. 建立素材库与参考画板
  4. 锁死配色纪律（只有一个红）
D5–D10

分镜与线稿

  1. 八页ネーム，先粗后精
  2. 自己读三遍，删掉 20% 格子
  3. 放大草稿 → 铅笔层
  4. 勾线（每天稳定推进 1.5 页）
D11–D17

网点与背景

  1. 背景打底（3D + 贴图）
  2. 灰度预算表逐页对照执行
  3. 网点粘贴 + 效果线
  4. 拟声词与效果字绘制
D18–D22

文字与输出

  1. 对白排版与气泡整形
  2. 统一检查：光源、线重、灰度
  3. 打印测试（缩到 60% 仍要读得懂）
  4. 导出交付 + 条漫版切图

流程能给你秩序，
但真正让一页立起来的，
是你敢不敢让角色沉默三格。

这份全案的所有设定、分页与台词均为示范原创，可作为你的练习模板自由改写。
建议的使用方式：把故事换成你自己的，但把流程、表格与自检问题原样保留下来走一遍——第一次完整走完，比画十张漂亮的单页更有价值。
